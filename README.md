# Deploying-and-Configuring-a-SIEM
Homelab: Splunk deployment through a virtual machine 

## Goal:
To become familiar with a common SIEM and understand the general process of setup, configuration, and monitoring. 

## Outline:
* Choose a SIEM
* Create Architecture (Deploy 3 VM's using VMware)
* Deploy the initial SIEM (SPLUNK Enterprise)
* Deploy SPLUNK Universal Forwarder on VM #2
* Deploy SPLUNK Auxiliary Endpoint
* Configuration of settings
* Generating Test Logs
* Visualization and Monitoring
